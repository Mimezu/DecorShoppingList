# Decor Shopping List

Decor Shopping List helps you collect the furniture and decorations you need for World of Warcraft Housing.

## Main features

- Automatically creates a shopping list for the decor you are missing when you import a Housing blueprint.
- Creates and manages multiple shopping lists from the Housing Decor Catalog.
- Adds **Add to Active List** to supported Decor Catalog right-click menus.
- Tracks decor vendors with map waypoints and visible vendor markers.
- Highlights the items you still need inside merchant inventories and displays the required quantity.
- Updates missing quantities as decor is added to your collection and automatically stops tracking completed items.

## Getting started

Open Decor Shopping List from the Addon Compartment or enter `/decorlist` or `/dsl`.

### From a blueprint

Import a Housing blueprint normally. Decor Shopping List detects its missing items and lets you save them as a new shopping list.

### From the Decor Catalog

Select the list you want to use, then right-click supported entries in the Housing Decor Catalog and choose **Add to Active List**.

### Shopping for decor

Use **Track** or **Track All** to add waypoints for available vendors. TomTom is supported when installed; otherwise, the addon uses the built-in waypoint system.

When you visit a merchant, decor required by your active list is highlighted directly in the merchant window with the quantity you still need.

## Useful commands

```text
/dsl
/dsl new <name>
/dsl use <name or id>
/dsl lists
/dsl blueprint <share code>
```

## Compatibility

- World of Warcraft Retail
- TomTom is optional

Vendor location data is based in part on Home Bound data imported with permission. Home Bound is not required to use Decor Shopping List.
